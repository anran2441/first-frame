# 迷你肉鸽 · 编程闯关课（raylib + C++）

用 C++ 和 raylib，从一个半成品出发，亲手把它变成能玩的俯视角肉鸽小游戏。
这是一门**多节课**的课程：每节课给游戏加一个新能力，边写代码边玩，用 Git 为每次进步存档。
面向刚学会 C++ 基础、第一次接触游戏与图形的初学者。

## 🧭 这门课怎么上

工作流每节课都一样，学会一次即可：

1. **复刻（只做一次）**：在 GitHub 把本库 **Fork** 到你自己的账号（**保持 Public**），
   再到复刻的 **Actions** 页点一次绿色按钮 **I understand my workflows, go ahead and enable them** ——
   复刻出来的仓库默认不跑任何工作流，不点这一步，之后每次 push 都不会触发评测，也不会有任何报错。
2. **记住两个远程**：`origin` = 你自己的复刻（往这里 push）；`upstream` = 老师的库（从这里取新课）。
3. **开始一节新课**：取回老师最新的课，从对应起点分支开一条**自己的**练习分支——

   ```bash
   git fetch upstream
   git switch -c my-lesson-N --no-track upstream/lesson-N   # N = 课号，例如 lesson-2
   ```

   `--no-track` 别省：不加它，这条分支会被挂到老师的 `upstream/lesson-N` 上，
   `git status` 会显示成跟它一致，忘了 `-u origin` 时 `git push` 也会报一段难懂的提示。

4. **只在自己的 `my-...` 分支上写、提交、推送**。
5. **小步前进**：写一点 → 编译 → 测试 → 通过 → `git commit` → 再写下一点。

> 详细的配置命令、每节课的手册，见课程网站。第一次用 Git，可看网站里的《Git 闯关指南》。

## 🌿 分支模型

| 分支 | 是什么 | 你能做什么 |
|---|---|---|
| `main` | **课程网站**（只有网站，没有游戏代码） | **只读**，不要改、不要往这里 push |
| `lesson-N` | 第 N 课的**起点**（前几课已实现 + 本课留空） | **只读**，作为你练习分支的出发点 |
| `my-lesson-N` | **你**从 `lesson-N` 开出来的练习分支 | 随便写、随便 commit、push 到你的复刻 |

## 🛠️ 构建与运行

> 下面这些命令在你自己的 **`my-lesson-N`** 分支上跑。`main` 上只有课程网站，没有可编译的代码。

编译/运行目标是 **Windows + MSYS2 UCRT64**（终端标题带 `UCRT64`）。在该终端进入本目录：

```bash
make          # 只编译        → build/game.exe
make run      # 编译并运行
make test     # 编译并跑自动评测（逐条报 [PASS]/[FAIL]）
make clean    # 清理产物
```

第一次若提示缺工具链或 raylib，安装一次（子系统要与终端一致，这里按 UCRT64）：

```bash
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-raylib
```

游戏操作：**WASD** 移动，**方向键**射击，死亡后按 **Enter** 重开。

## ✍️ 你要做什么

每节课，`src/main.cpp` 里都有几处标好序号的 **`★TODO`**。跟着课程网站对应那节课的手册，
按顺序把它们填上；照已经写好的函数的写法模仿即可。每填一处就自查：

```bash
make test     # 全绿即对；出现 [FAIL] 就照它提示的 expected / got 改
```

自动评测只管得了逻辑；画面类的改动（贴图、布局等）请 `make run` 亲眼看一遍。
每节课要填哪些、每个 TODO 的详细提示，见课程网站，以及**你分支上**的 **`学生手册-TODO说明.md`**。

## 📁 仓库结构

`main` 上**只有课程网站**，没有游戏代码：

```
README.md                    这份说明
docs/                        课程网站（GitHub Pages 从这里发布）
.github/workflows/grade.yml  自动评测 CI 的定义（push 到 my-lesson-* 时跑）
```

游戏代码、素材、评测、手册都在**每节课的起点分支** `lesson-N` 上；你 fork 后从它开出
自己的 `my-lesson-N`，在那边工作。你的分支上会有：

```
src/main.cpp             游戏源码（含本课的 ★TODO）
src/                     其他源码/头文件（如贴图门面 assets.h）
tests/test_todos.cpp     自动评测
assets/                  游戏素材（贴图等，随课程增加）
学生手册-TODO说明.md      本课每个 TODO 的详细提示（按课更新）
Makefile                 构建脚本
```

## 🗺️ 课程安排

从「会动会打」一路做到完整可通关的肉鸽。大致的能力线（以课程网站的地图为准）：

会动会打 → 怪物图鉴（类型 + 配置表）→ 关卡地图 → 障碍碰撞 → 敌人 AI（状态机）→
掉落与道具 → 关卡推进 → 手感打磨（HUD / 音效）。后续还有可选的随机地牢生成与打包收尾。
