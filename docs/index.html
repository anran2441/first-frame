迷你肉鸽 · 编程闯关课

一节课一节课，把一个半成品，亲手养成一个能玩的俯视角肉鸽游戏。用 C++ 和 raylib，边写边玩、边学 git。

🔧 第一次配置（只做一次）

这门课的代码在老师的公开库 xianyudd/first-frame。你先复刻（fork）一份到自己账号，之后每节课都在自己的复刻里写。

  1. 在 GitHub 打开 xianyudd/first-frame，点右上角 Fork，复刻到你自己的账号。
  2. 把你的复刻 clone 到电脑（<你> 换成你的 GitHub 用户名）：
git clone https://github.com/<你>/first-frame.git
cd first-frame
git remote add upstream https://github.com/xianyudd/first-frame.git   # 记住老师的库，取新课用
git config commit.template .gitmessage                                # git commit 弹出中文模板
两个远程origin = 你自己的复刻（往这里 push），upstream = 老师的库（从这里取新课）。记混了就 git remote -v 看一眼。

🗺️ 课程地图

点亮的课，进去就能开始；灰的还在做。每节课都在上一节的基础上，给游戏加一个新能力。

1 会动会打的游戏

填 4 个函数：子弹飞行、四方向射击、击中得分、敌人追人。练 for / if / 数组 / 碰撞检测。

 可开始
2 怪物图鉴

给游戏换上真正的贴图，加入多种「打法不同」的敌人：快速、重甲、冲刺、分裂……练类型 + 配置表、状态机。

 制作中
3 我的竞技场

用格子地图设计自己的关卡：铺地面、摆装饰、定玩家出生点和刷怪点。练二维数组、坐标换算。

 敬请期待
4 真正的障碍

让墙真的挡住人：玩家、敌人撞墙停下，子弹撞墙消失。练碰撞响应、逐轴试探。

 敬请期待
5 敌人的招式

敌人会巡逻、警觉、追击、攻击，还会绕开墙找到你。练状态机、BFS 网格寻路。

 敬请期待
6 掉落与道具

打怪掉血包、金币、武器；捡起来就变强。练掉落表、增益系统（复用配置表思路）。

 敬请期待

▶️ 每节课怎么开始

配置好之后，每开一门新课就两条命令 —— 从老师的最新起点，开一条属于你自己的分支。

git fetch upstream                            # 取老师最新的课
git switch -c my-lesson-2 upstream/lesson-2   # 例：从第2课起点开自己的分支
  • 只在自己的 my-... 分支上写、存档（commit）。
  • main 和 lesson-* 是只读起点，不碰、不推。
  • 想备份成果：git push -u origin my-lesson-2（推到你的复刻）。
📏 铁律写一点 → 编译 → 测试 → 通过 → 存档 → 再写下一点。一次只碰一个 ★TODO。
