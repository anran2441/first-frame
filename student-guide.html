第3课 · 大地图 → 镜头 → 碰撞 → 声音

我的竞技场

让地图比窗口大，让镜头跟着你，再让墙挡住身体、声音跟着事件响。你已经能读C++；这一课练习自己查API、做小实验、解释结果。十项可以分几次完成，不要求两小时赶完。

三步找到当前任务

  1. 打开 src/main.cpp，读文件头任务目录；第10在 src/my_cases.h。
  2. 在这份课包的MSYS2 UCRT64终端运行 make todo，查看真实文件位置。行号会变化，别背行号。
  3. 从下面任务复制唯一 TODO(L3-xx...) 标记，回到指定文件按Ctrl+F。只改这项区域，先读前后代码，不复制整个函数答案。
make todo
make run
make test

在自己的复刻仓库根目录、my-lesson-3 分支运行。起点能编译，但尚未完成的任务会失败。先做当前阶段；不要改tests来换绿灯。WASD移动，方向键射击，G看格线/身体框，ENTER重开，TAB切练习/战斗，Escape退出。

老师已准备资源与音频生命周期，也把镜头初始化、移动后每帧更新的调用挂好了。扩地图、镜头函数内容和绘制分层仍由你实现。音频加载/每帧更新/释放不是本课填空，别把声音加载放进循环。

每一项都按这个顺序自己学

  1. 查资料：在raylib头文件或官方cheatsheet查本项API，记下参数、返回值、坐标单位。先说出你不懂的词。
  2. 最小实验：只试一个矩形、一个字段或一个调用；可先用纸画图，再在自己的临时实验文件验证。
  3. 预测：运行前写下会发生什么、为什么。
  4. 实现：回到标记，只处理本项目标。
  5. 验证：make test看对应组，再make run亲自观察。记下预测与实际的差别。
  6. 解释：不用读代码，回答本项问题；说出哪份资料支持你的做法。

提示默认收起。先自己查，再按“概念 → 思路 → 局部实验”逐级打开；卡住可以请老师帮助定位，但保留你的预测和推理。

离线资料：在MSYS2安装目录的 ucrt64/include/raylib.h 搜索 Camera2D、BeginMode2D、EndMode2D、CheckCollisionRecs。这些语义已据本机官方头文件核对；没有声称在线文档抓取成功。可主动打开 raylib官方cheatsheet查签名；页面本身不会加载任何外部资源。

世界坐标与屏幕坐标

世界：墙和角色在地图中的位置。屏幕：像素在窗口中的位置。镜头改变你看见哪一块世界，不改角色矩形和墙的世界坐标。

地图行列 × TILE → 世界宽高
世界中的玩家中心 → camera.target
窗口中的屏幕中心 → camera.offset
zoom = 1，rotation = 0

例如世界点(1800,900)可以映射到屏幕中心(640,360)，无需把角色位置减掉1280。碰撞始终比较世界矩形。初版无平滑或边缘夹紧，靠世界边缘看到镜头外空白可以接受。当前用方向键射击，没有鼠标瞄准任务；GetScreenToWorld2D以后有鼠标输入再研究。

停止点三 · 声音与自己的证据

卡住时，带这五行来讨论

预期：我认为会……，依据是……
实际：实际看到……（附任务号与错误消息）
尝试：只改变了……，结果……
最小代码：保留能复现问题的最小片段
推断：可能是……；下一步只验证……

每次只改一个原因。编译报错先看第一条与相关类型；运行错误先分清坐标、更新、绘制还是事件时机。镜头不跟随查03/04与调用顺序；世界动而文字也动查05范围；穿墙先查02再06再07；没声音先区分事件没调用与老师提供的音频设备/资源问题。
